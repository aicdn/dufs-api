Dufs API

文件列表与下载链接接口

API 端点

GET /
API 基本信息
GET /files?path=/
列出目录下的所有文件，返回文件名、路径和下载链接
GET /files?path=/&q=*.txt
搜索文件（支持通配符）

请求示例

# 列出根目录文件
GET https://your-project.edgeone.app/files?path=/

# 搜索 txt 文件
GET https://your-project.edgeone.app/files?path=/docs&q=*.txt

# 列出子目录
GET https://your-project.edgeone.app/files?path=/images

响应示例

{
  "path": "/",
  "files": [
    {
      "name": "readme.txt",
      "path": "/readme.txt",
      "isDir": false,
      "url": "https://dufs-server.com/readme.txt"
    },
    {
      "name": "images",
      "path": "/images/",
      "isDir": true,
      "url": "https://dufs-server.com/images/"
    }
  ],
  "total": 2
}
